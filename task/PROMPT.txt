给离线档案清单编写一个稀疏 Merkle 批证明检查器。键是固定深度的二进制串，值是 UTF-8 字符串或缺席。定义叶哈希为 SHA256(0x00 加四字节大端 UTF-8 字节数加内容)，缺席叶为 SHA256(0x02)，父节点为 SHA256(0x01 加左哈希原始字节加右哈希原始字节)。两个清单版本的已知根来自输入可信登记。变更只能发生在声明的受审键集合中；证明提供每个受审键变化前后的值及其他区域的共享旁枝，同一旁枝摘要用于同时复原前后根。旁枝前缀必须恰好对应受审叶诱导树的边界，禁止重复、父子重叠、额外、缺失或覆盖受审叶。受审键还需通过输入声明的增删改方向和允许变更的前缀范围。
verify 对批证明复原旧根与新根，输出每个声明键的变更分类及完整校验结果；merge 将同一根对的两个可验证证明合并成受审键并集的唯一最简证明，要求重叠叶一致、可展开的旁枝摘要与展开后相符。merge 不改变原始可信根与策略，分别验证两个输入，以及合并结果。深度支持到 128，不得构造完整树；旁枝按二进制前缀字典序输出。测试覆盖缺席与空串不同、一个证明的旁枝恰被另一份展开、只变更未声明键会导致双根核对失败、合法证明被重复旁枝扩充、并集合并与顺序无关，以及小树全量计算对拍。

增加离线 proof-rebase 命令。库存方持有旧根 A 上对固定键集合 S 的普通单根最简证明；审核方只提供从 A 到 B 再到 C 的任意长度双根变更证明链，每一跳各自可能修改不同键集合 T。将 S 投影到最终根，输出 S 的最新值、C 的最简普通旁枝，以及每个 S 键发生真实值变化的首尾跳次。要求根据 T 的变化树只替换 S 证明中相应旁枝，旧值和旧旁枝摘要一旦被两份证据分别约束则须独立核对；不能从单根输出中推断未被披露的旁枝内容。链每跳的双根、根连续性及版本次序先独立校验；其中任一跳不完整或政策不符时不输出 C 证明。支持同一跳的证据从多个乱序输入文件到达，split-verify 独立验证每份分片的形状和已绑定根对，证据全集组装后才复原根；额外、缺失或冲突分片给出第一处无法核对的前缀。不展开全树。测试用小树核对补丁多次覆写同一键、S 与 T 完全不相交仍需更新旁枝、回到旧摘要仍需保留历史变化、多个嵌套旁枝被部分展开以及证据分片重放。

把以上离线校验接入多进程档案发布账本。归档服务在两个摄取通道上同时接收乱序证据：版本检查点、前后版本的双根批证明分片、审查员投票及撤票。检查点 ID 不由根摘要决定，内容回滚到完全相同的根仍是不同检查点。每条跳转边绑定起止检查点、目标归档用途、保持不变的旁枝，以及允许变化的前缀政策；所有边按检查点的递增登记代次形成 DAG。一个发布请求从上一次发布回执指向指定终点检查点，固定提交时看到的政策版本和自己的 S 键集普通证明；不能按相同根摘要跳过中间节点。

每一跳还需为每个被修改的敏感类别选择两套独立审查签票，票绑定这条边、前后根、政策版本及其覆盖的类别，且绑定当前逻辑有效期。对一个发布请求，同一票和同一审查主体全路径最多只能使用一次，即使跨跳、跨类别或登记在同一人的别名下。审查票的机构也必须在同一类别的两张票间不同。当前发布账本已经消费的票不能再用于后续发布。plan 在 DAG 中联合选择证据完整的可达路径和全局互不冲突的票，先最小化全部跳中被实际披露过的不同键数量，再最小化跳数，最后按边 ID 序列和按 (跳次,类别,票 ID) 排序的列表决胜。相同检查点上消耗过两套不同票的状态不能合并。给出失败原因是结构断链、有效票不够还是最终目标未登记；每条可执行路径必须能独立 rebase 并验证 S 的最终证明。小规模用路径乘票分配的穷举独立校验，正式实现支持 150 条边，候选全局审查主体至多 30 个，禁止假定逐跳最优即全局最优。

publish 在 SQLite 同一事务复核当前起点检查点、所选边的证明分片集合哈希、政策代次、票撤销/消费和幂等请求 ID，再提交全部票消费、最新根与 S 的投影证明。并发争用同一张票或同一起点只允许先提交的一方发生状态变化。重复报文同内容返回原回执，异内容拒绝。摄取可以先暂存只包含部分数据的证据，但无论进程何时中断，它都不能被查询成已验证边或使查询组合出两个版本的根和证明。历史 view 按提交号回读，不因后来撤票改变。必须用两个独立进程及可重复同步点验证发布与撤票抢先、进程提交前中断、提交后响应丢失。另构造旧根和最终根相同但中间改过 S 的分支、边数更短却占用了后跳唯一审查人、同一隐私键重复修改只计一次泄露成本、同根不同检查点、以及旧政策下有效的合并证明被当前计划并发拒绝。

从空仓库交付一套可在 Windows 原生 Python 3.12 上离线运行的实现，只用标准库和 CPU，夹具全部使用本地虚构数据。使用 `python -m solution <命令> CASE.json` 运行，读写持久状态的命令另传 `--db DB.sqlite`。结果写到标准输出，采用 UTF-8 JSON，同一逻辑输入的结果必须一致。结构错误应标明错误码和字段位置。README 写清完整输入输出定义和复现步骤，附可直接运行的样例和断言测试，测试入口为 `python -m unittest discover -s tests -v`。
